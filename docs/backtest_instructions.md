# 定期バックテスト 指示書（玉屋本店版）

別セッションの Claude に「バックテスト更新して」と頼む時に、この文書とエクスポートJSONを一緒に渡す。

## 渡すもの
1. 最新のエクスポートJSON（共通設定 →「エクスポート」。ファイル名 `tamaya-honten-export-YYYY-MM-DD.json`）
2. 最新の `src/App.jsx`
3. この文書

## やること
1. `node tools/backtest.mjs <export.json>` を実行（ウォークフォワード：各日、前日までのデータだけで学習して翌日を予想）
2. ページ別・全体の「グレード別の翌日☆〇率」「翌日勝率（差枚プラス率）」を表にする
3. 目標：**S〜E の開きを広げる**（S＞A＞B＞C＞D＞E の順に☆〇率が下がるのが理想）
4. 見直し候補（必ず実データで比較してから変える）
   - グレード境界（初期値 S≥60 / A≥30 / B≥10 / C≥-10 / D≥-30 / E）。点数が大きく出やすい（S・Eに偏る）場合は境界を広げる
   - 記号の閾値（p20/p50/p80）・判定不可の回転数（上限の25%未満）
   - 信頼度の上限（通常時3900／総回転数8000）
   - 強い／準イベントの分類（イベント名ごとの翌日☆〇率を実測してから）
   - 効かないパターン・逆に効いているパターン（学習済みパターン一覧の n と点数）
5. 変える時は `APP_VERSION` を上げ、変更内容と検証結果を App.jsx 冒頭のコメントに残す

## 守ること
- 数値は実データで検証してから言う。未検証の原因を断言しない
- 前半／後半に分けても同じ方向に効くかを確認する（後半だけ効く見せかけの効果に注意）
- 他店（プラザ2・雑餉隈）の数値を持ち込まない
- 成果物は ASCII のファイル名で出す
